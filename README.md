## 🖖Introduction

DHTerminal is a modern tabbed terminal for Windows by Group DH, in the style of the new Windows Terminal. It finds every shell on your PC by itself and puts them in one dropdown: Windows PowerShell, PowerShell 7, Command Prompt, every WSL distro (Ubuntu, Debian, Kali, openSUSE, Alpine, Arch, Fedora, ...), Git Bash, MSYS2, Cygwin, the Visual Studio developer shells and your SSH hosts.
